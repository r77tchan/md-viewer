# .kagayoi

このディレクトリには、KAGAYOI Engineering がこのリポジトリから読み込む設定を置く。

## フェーズ指示

`instructions/design.md`、`instructions/implement.md`、`instructions/review.md` は、Host が各フェーズで Agent に渡す既定の指示を置き換える。
置き換わるのはフェーズ指示だけで、共通ルールとフェーズの約束事（報告の仕方など）は常に適用される。

- Host はこれらのファイルを、作業ツリーや PR のブランチではなく、デフォルトブランチから読む。反映させるにはデフォルトブランチにコミットする。
- ファイルを削除するか空にすると、既定の指示に戻る。
- シンボリックリンクは読まれない。通常のファイルを置く。

`kagayoi init` は、実行した時点の版の既定の指示を書き出す。その後に既定の指示が変わっても、これらのファイルは更新されない。
