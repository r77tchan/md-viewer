# 指示

## ルール

- このファイルはAIが編集しないこと。
- AIの永続メモリは使用しない。セッションをまたいで残す情報は `doc/メモ.md` に書く。
- 勝手に進まないこと。ユーザーに進めて良いか確認すること。

## プロジェクトの目的

Markdown ファイルをブラウザで閲覧するためのアプリ。閲覧専用で、編集や内容の保存はしない。

- 手元の .md ファイルを開く（ファイル選択・ドラッグ＆ドロップ）
- GFM（表・チェックリストなど）、コードのシンタックスハイライト、ダークモード、目次
- 技術スタック: Vite + React + TypeScript、HeroUI v3 + Tailwind CSS v4、Vitest、npm
- DB・サーバーは持たない。GitHub Pages で公開する
